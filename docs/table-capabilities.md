## 通用规则

- 五张分页表均由服务端排序/筛选，不只处理当前页。列头三态，最多 3 项排序，最终以 id desc 兜底；不排序时恢复各表原默认序。枚举按存储码排序；可空字段沿用 GreatSQL 的 ASC 空值在前、DESC 在后。
- 关键词/快捷条件/最多 5 条列级条件同时以 AND 生效；日期按上海自然日含结束日，维修 DATE 列保持日历日口径。筛选或排序变化重新加载第 1 页，保留已渲染内容直到响应到达。
- 默认计数复用 meta.pagination.total，为当前筛选后的全量，不是当前已加载数；分组只支持下列枚举，按需随同一列表 HTTP 响应返回 meta.summary。邀请码派生状态按同一服务端 now 串行计数，不另开一组并发请求。无求和/耗时/统计结果导出。
- 每次 20 条，服务端上限仍为 100；沿用连续加载和“已加载/总数”，不改成另一套翻页。输入仅在应用时发请求，不逐字查询；旧条件请求取消，迟到结果丢弃。
- 清除同时恢复关键词、快捷条件、列级条件、排序与分组；列宽偏好用高级面板独立恢复。分类/技能无查询条件，清除入口禁用并说明，拖动序不被重置。
- URL 仅恢复受控排序、日期与枚举条件；姓名、QQ、手机号、学号、批次等文本不写页面 URL/持久存储。刷新/回退恢复可分享部分，连续加载从第一页重新读取。
- 成员、维修和报名导出复用列表筛选与排序，覆盖全部匹配记录；超限拒绝，不静默截断。维修/报名保留原列及权限/审计；成员导出同时要求 member:manage 与 data:export，QQ/手机号脱敏且不导出邮箱。文本条件值不进入新增审计摘要。
