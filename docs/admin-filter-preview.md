# 后台筛选低保真预览

依据 [方案构思](admin-filter-concepts.md)，基线 `3fac280`，开发分支 `feat/admin-filter-previews`。

在仓库运行 `pnpm dev`，打开 <http://localhost:3000/dev/admin-filters>。路由仅在 `NODE_ENV=development` 下呈现，其他环境调用 `notFound()`；未加入公开导航。全部使用虚构数据与内存请求模拟，不调用业务写接口，不保存查询文本到 URL 或本地存储。

## 可以比较什么

- 成员管理：A 短搜索与浮面板、B 统一查询抽屉、C 折叠查询带
- 维修审核：A 与 D 状态页签；D 默认为全部，切换状态保留搜索、分类及排序
- 招募申请：B 同时承载批次、关键字、审核状态与账号开通状态
- 审计日志：B 仅显示操作、结果，没有搜索输入
- 成员与维修另有只读的现有 `AdminTableQuery`，用于布局基线比较

标题下方的“切换预览方案”常驻显示 A/B/C/D 与基线按钮；选择当前场景不支持的方案会自动切换到对应场景，D 进入维修审核，其余进入成员管理。同场景切换方案保留查询，跨场景切换恢复默认。控制台提供默认、多个条件、未应用草稿、长标签、零结果、五秒刷新和失败保留旧结果样例；也可以勾选下次请求失败再操作。

打开、输入、应用、取消、关闭、移除单项、清除和重置可交互。A 搜索与快捷筛选分别提交；B 所有字段集中应用，应用分组后保持抽屉打开显示计数；C 收起保留草稿，取消丢弃草稿。清除筛选保留排序与分组，重置查询恢复全部默认。长标签可点击查看完整值。

列表提供选择、批量入口示意、当前结果 CSV 导出、排序、分组计数和加载更多。新增与批量写操作仅显示说明。列宽使用浏览器原生调整作为占位；这些能力没有接入生产表格状态机。

## 验证与限制

已运行：

- 改动 TS/TSX 的 ESLint、四个实现文件的 Prettier、`pnpm exec tsc --noEmit`，通过
- 开发路由 HTTP 200；CDP 断言覆盖应用摘要、草稿隔离、取消、C 收起继续编辑、清除与重置范围、失败保留旧列表、重试、审计无搜索、Esc 及焦点返回
