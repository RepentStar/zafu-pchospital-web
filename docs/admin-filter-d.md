# 后台搜索与筛选收纳：D 方案实施说明

> 已确定采用 D 方案：常用状态页签 + 按需搜索与更多筛选
>
> 来源提交：[`cc9a2c66e51ffff732c7ac61220105b7afc2b69b`](https://github.com/ZAFU-PCHospital/zafu-pchospital-web/commit/cc9a2c66e51ffff732c7ac61220105b7afc2b69b)；关联 [Issue #274](https://github.com/ZAFU-PCHospital/zafu-pchospital-web/issues/274)

## 目标与范围

让列表成为后台首屏主体：常用状态可以直接切换，搜索和其他条件按需打开；收起后仍能看清当前查询范围。

本说明从上述提交的 D 预览提炼，**以维修审核作为首个实现和验收场景**。D 方向已经确定，不再进行 A/B/C/D 选型。现有 D 仅覆盖维修，不能据此认定其他后台页面的状态轴、页签及默认值也已确认；后续迁移应使用各页已有字段，不新增业务队列。招募有审核、账号开通两个状态轴，不能同时铺成两排页签；审计页不虚构搜索输入。

本轮交付说明和独立 HTML，未替换生产组件。原始 [方案构思](https://github.com/ZAFU-PCHospital/zafu-pchospital-web/blob/cc9a2c66e51ffff732c7ac61220105b7afc2b69b/docs/admin-filter-concepts.md) 和 [四案预览记录](https://github.com/ZAFU-PCHospital/zafu-pchospital-web/blob/cc9a2c66e51ffff732c7ac61220105b7afc2b69b/docs/admin-filter-preview.md) 保留为历史参考，其中“尚未选型”“优先 A”等建议不再作为本轮选型结论。

## 页面结构

```text
维修审核
全部  待审核  已通过  已退回  草稿       搜索  更多筛选  高级
（点击搜索后）搜索维修记录 [                 ] [搜索]
（有条件才出现）搜索：林 ×  状态：待审核 ×  分类：软件问题 ×  清除筛选
排序：日期 ↓  ·  分组：状态（如已设置）              重置查询
共 N 条                                  批量操作 · 导出 · 刷新
──────────────────────────────────────────────────────────
设备 / 故障       提交人       分类       状态       维修日期
```

- 状态页签用轻底色或下划线，保持工作区密度；不为每个状态铺大色块
- 桌面展示全部及已有四个状态，包含草稿；窄屏改为“审核状态”选择器，搜索、更多筛选、高级仍是文字入口
- 默认沿用现有页面；提交中的预览默认“全部”，不擅自改成“待审核”
- 搜索默认收起，展开后支持 Enter 或搜索按钮提交；中文输入法确认不触发查询
- 更多筛选仅编辑分类等其他快捷字段，不重复放状态；高级条件、排序及分组沿用既有高级入口
- 已应用条件逐项展示并可移除。长值截断后可点击或键盘打开完整值；条件过多可折叠为“其余 N 项”，清除入口保持可达
- 不显示页签数量；当前分页条数不能充当各状态总数。排序、分组单独展示，不计入筛选数量

## 查询行为

| 操作                      | 修改范围                       | 必须保留                                         |
| ------------------------- | ------------------------------ | ------------------------------------------------ |
| 切换状态                  | 仅快捷 `status`，立即查询      | 已应用关键字、分类、列级条件、排序、分组         |
| 选择全部                  | 仅取消快捷 `status` 限制       | 其他条件，包括高级中的状态条件；对应标签继续可见 |
| 搜索提交                  | 仅关键字，去除首尾空白         | 状态和其他已应用设置；不提交其他入口的草稿       |
| 收起搜索                  | 仅关闭输入区域                 | 已生效关键字及摘要；未提交输入留在当前内存会话   |
| 应用更多筛选              | 仅该面板负责的快捷字段         | 状态、搜索、高级条件、排序、分组                 |
| 取消 / Esc / 关闭筛选弹层 | 丢弃该弹层本次草稿             | 已应用条件和旧结果；焦点返回入口                 |
| 应用高级                  | 列级条件、排序、分组           | 快捷状态、分类和已应用搜索                       |
| 移除单项                  | 仅该标签对应字段 / 条件        | 其他条件和排序、分组；移除状态同步更新页签       |
| 清除筛选                  | 关键字、全部快捷字段、列级条件 | 排序和分组                                       |
| 重置查询                  | 使用既有完整 reset 语义        | 恢复默认查询；列宽仍由既有独立机制管理           |

“全部”是当前状态维度的全部，不是全库全部。快捷状态与高级状态条件共同生效；冲突时允许零结果，不能暗中覆盖高级条件。

摘要来自已提交查询，不能显示输入中的草稿。提交后异步请求期间保留旧列表和旧数量，说明“结果尚未更新”；失败继续保留并提供重试。新条件成功返回后再呈现对应结果，迟到响应不得覆盖更新的查询。计数、分组统计和导出必须与其对应的结果查询一致；不能把旧结果的数量或导出标为新条件的结果。

## 实现边界与复用

改造应围绕现有查询状态和页面能力，不新增一套查询协议：

| 入口                                                                  | 复用职责                                           |
| --------------------------------------------------------------------- | -------------------------------------------------- |
| `AdminTableQuery`、`useTableQuery`、`query-state`                     | 快捷字段、列级条件、排序、分组、URL 白名单与 reset |
| `AdminFilterDialog`、`AdminModal`                                     | 高级编辑、取消、Esc、焦点和滚动管理                |
| `AdminListToolbar`、`useAdminList`、`AdminListEnd`、`AdminBatchTools` | 结果刷新、加载更多、选择与批量、导出入口           |
| `table-queries`、`admin-tables`、`admin` 配置                         | 字段能力、默认值与产品文案                         |
| `Button`、`Icon`、`.field__input`、语义令牌                           | 主题、控件、焦点与触屏可用性                       |

`AdminTableQuery` 的已有五个调用方为 `MemberAdminPanel`、`RepairAdminPanel`、`JoinApplicationAdminPanel`、`InviteCodeAdminPanel`、`AuditLogPanel`。正式修改公共 API 前重新搜索消费者，保持兼容或在同一变更内贯通；不要给其他四页直接套维修的状态枚举。

保留表头排序、多排序优先级、分组统计、列宽、加载更多、批量操作及导出。换查询时按既有页面规则处理选择；仅打开、关闭输入或弹层不清选择、不重挂整张表、不自动滚动。自由文本不写 URL、localStorage 或查询历史；可恢复字段仍按现有白名单处理。

本轮没有公共组件 API、API Contract、Schema、Migration 或依赖变更。正式接入优先在现有能力内完成，不因选中 D 自动扩展业务范围。

## 独立 HTML 预览

文件：`admin-filter-d.html`（随附 ZIP，仓库中位于 `docs/previews/`）。下载后直接用现代浏览器打开；CSS、脚本、虚构数据均内置，不需要 Node、项目服务、账号或网络。

预览仅保留 D，无其他候选方案切换。可以操作状态、搜索、分类、高级日期条件、两级排序、状态分组、标签、清除和重置，并演示零结果、长标签、刷新与失败重试。列表选择、加载更多和 CSV 导出为样例演示，批量操作仅提示，不执行真实业务操作。

日期条件是列级筛选的代表，不是完整生产高级编辑器；独立文件不验证真实权限、服务端分页、URL 后退恢复、列宽或完整导出逻辑。内存模拟成功不等于业务验收通过。预览的布局尺寸仅作实现起点，没有沿用四案记录中的历史首行测量结果。

GitHub Issue 正文可使用本说明；HTML 建议压缩为 ZIP 附件上传，下载解压后打开。GitHub Issue 不会直接运行附件中的 HTML；预览与本文应随附同一版本。

本轮实跑：Edge 以 `file://` 离线打开，30 项 DOM / 交互断言通过，覆盖草稿隔离、状态切换、取消及焦点返回、清除 / 重置、长标签、零结果、在途 / 失败 / 重试、选择保留、加载更多和较新请求覆盖旧请求；1440、760、759、390、320px 无页面横向溢出、弹层未超出视口。页面运行时异常和外部 HTTP 请求均为 0；Prettier、内嵌脚本语法和差异空白检查通过。未验证真实手机软键盘和生产业务；未运行全量 lint / test / build 或数据库测试，本轮仅新增交接文档及离线原型。

## 正式接入验收

- [ ] 默认值和状态枚举与现有维修页一致；桌面页签、窄屏选择器同步，不出现估算计数
- [ ] 状态切换仅改 status；“全部”保留其他约束，尤其是高级状态条件

- [ ] 长条件可键盘查看完整值；无条件不留空摘要；320px、390px 和桌面下入口可达、无页面横向溢出
- [ ] 弹层焦点圈、Esc、焦点返回、滚动锁和折叠区 Tab 顺序正确
- [ ] 在途 / 失败保留旧列表并标明口径，重试正确；迟到请求不覆盖新结果
- [ ] 真实 URL 白名单、后退恢复、导出、分组、批量选择、列宽和加载更多通过对应回归
