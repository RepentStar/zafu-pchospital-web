## 安全说明

- Session 存储与 Cookie：随机 32 字节令牌，数据库只存 `HMAC-SHA-256(AUTH_SECRET, token)`；Cookie 使用 HttpOnly、SameSite=Lax、Path=/，生产环境 Secure。
- 登录限流：QQ + IP 以不可逆摘要写入 `LoginThrottle`，失败窗口和封禁可供多实例共享，不保存原始 QQ 或 IP。
- CSRF / 同源校验：所有 Cookie 认证写接口校验 `Origin` 与 `Host` 同源。
- 密码与敏感日志检查：密码使用 scrypt；不存在账号执行占位哈希校验；日志和审计不记录密码、Session、邀请码明文或完整联系方式。
